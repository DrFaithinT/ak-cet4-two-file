# CET-4 双文件版 v2.0

CET-4 全真模拟考试系统「双文件」运行版：一个自包含网页 + 一个零依赖的 Python 本地启动器。

网页负责考试流程与界面；启动器只做一件事：在本机 `127.0.0.1` 上开一个小服务，代理 B 站听力音频，绕开浏览器直连时的 412 风控，并提供 `Range` 支持，让听力可以拖动进度条。

本项目基于 [DarkModest/ak-cet4](https://github.com/DarkModest/ak-cet4) 的单文件版继续开发，界面升级为 v2.0，并新增双文件本地运行方式。

## 功能

- 📄 **真题 PDF 本地解析**：拖入试卷 PDF，自动划分写作 / 听力 / 阅读 / 翻译
- ⏱ **全真计时**：按各节倒计时，到时自动交卷
- 🎧 **听力**：支持本地音频文件，或直接选 B 站真题合集分 P
- 🧩 **段落匹配**：点题干 → 点段落，支持同一段落重复使用、A–P 快捷键
- 💾 **断点续考**：刷新或关闭页面后，下次可恢复上次进度
- 📊 **本地评分**：生成成绩单，导出或复制 Markdown 报告
- 🌙 **深色模式**：v2.0 界面（Formal Academic CBT 风格）

## 两个文件的分工

| 文件 | 作用 |
|---|---|
| `cet4_exam.html` | 考试系统本体；PDF.js / worker / CMap 全部内联，离线也能解析 PDF |
| `cet4_launcher.py` | 本地启动器；只用 Python 标准库，仅监听回环地址，代理 B 站音频 |

## 快速开始

1. 安装 Python 3（3.8 及以上）
2. 下载本仓库的两个文件，放在**同一个文件夹**
3. 在该文件夹执行：

   ```bash
   python cet4_launcher.py
   ```

   Windows 也可以直接双击 `cet4_launcher.py`
4. 启动器会自动打开浏览器；没有自动打开，就手动访问终端里打印的地址
5. 考试期间保持终端窗口开着，考完关闭即可

不需要 `pip install` 任何东西。

## 启动器做了什么

- 从 B 站官方 finger/spi 接口获取 `buvid3` / `buvid4`，降低被风控概率
- 依次尝试三种取流方式：页面 `__playinfo__` → WBI 签名接口 → HTML5 直链接口
- 三种都失败时，如果本机装了 `yt-dlp`，再兜底试一次（没装就跳过）
- 音频下载后缓存到 `bili_cache/`，下次直接命中
- 网页通过 `/api/bili-audio` 取音频，服务端支持 `Range`，所以进度条可以拖动

## 隐私与缓存

- 启动器只绑定 `127.0.0.1`，不会对局域网或公网开放
- 试卷解析、评分全部在浏览器本地完成，不上传任何服务器
- `bili_cache/` 是音频缓存，可随时删除
- 如果本机 IP 被 B 站 412 限制：在同目录新建 `bili_cookie.txt`，粘贴浏览器登录后的 B 站 Cookie。**该文件包含账号凭据，不要提交到 Git，也不要发给别人**
- 仓库的 `.gitignore` 已忽略缓存与 Cookie 文件

## 常见问题

**Q：提示「未找到 cet4_exam.html」**

两个文件必须放在同一目录，且文件名不能改。

**Q：B 站听力一直失败**

先确认网络能正常打开 B 站；仍然失败，就按上面的方法放 `bili_cookie.txt`。也可以直接改用本地音频文件，跳过 B 站。

**Q：可以不启动 Python，直接双击 HTML 吗？**

可以，考试功能照常；但 B 站听力会退回官方网页播放器，不能拖动进度条，也更容易遇到 412。

**Q：端口是多少？**

每次随机分配，终端会打印实际地址。
